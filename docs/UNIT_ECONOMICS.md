# Plana — Юнит-экономика и стоимость эксплуатации

> Документ для инвесторов и принятия решений по ценообразованию.
> Дата: 2026-05-19. Все цифры API — эмпирические, из дашборда OpenAI.
> Валюта: USD. Цифры — оценки, помечены допущения.
>
> **Требует обновления:** engine по умолчанию использует `gpt-image-2`, а часть
> UI и расчётов всё ещё опирается на фиксированные оценки `gpt-image-1`.
> Перед использованием в финансовой модели нужно подключить фактический usage
> accounting и сверить тарифы с https://openai.com/api/pricing/.

---

## 1. Резюме для инвестора

Plana — AI-платформа концептуального архитектурного проектирования для девелоперов.
Себестоимость одного проекта — **$1–5** (в основном генерация изображений через OpenAI).
Ценность для клиента — **недели работы архитектора** (десятки–сотни тыс. $ экономии на концепт-стадии).

**Ключевой вывод:** себестоимость не является ограничителем бизнеса.
Валовая маржа при любой разумной цене **>90%**. Ограничитель — продажи и ценообразование,
а ближайший операционный риск — **отсутствие квот** на пользователя.

## 2. Структура затрат

| Статья | Природа | Драйвер |
|---|---|---|
| Генерация изображений (OpenAI) | Переменная | Кол-во сгенерированных картинок |
| GPT-4o текст (нормы, enhancer, vision) | Переменная | Кол-во проектов (небольшая) |
| VPS (хостинг) | Фиксированная | Не зависит от объёма (до предела) |
| Layout / DXF / IFC / валидация / ТЭП | $0 | Чистый расчёт на сервере |

**Базовые юниты (эмпирические):**

- 1 изображение: **$0.15–0.20** (среднее в расчётах: **$0.175**)
- GPT-4o текст: **~$0.10–0.20 на проект**
- VPS: **$11–15 / мес** (среднее: **$13**)

## 6. Юнит-экономика на одного пользователя (B2B)

**Пользователь** = аккаунт девелоперской/проектной компании (seat).
Допущение по интенсивности (концепт-проектов в месяц на пользователя):

| Профиль | Проектов/мес | Себестоимость/мес (полный $2.5) |
|---|---|---|
| Лёгкий | 3 | **$7.5** |
| Активный | 10 | **$25** |
| Power | 30 | **$75** |

### Маржа при разных моделях цены

**Подписка (за пользователя в месяц):**

| Цена подписки | Лёгкий ($7.5) | Активный ($25) | Power ($75) |
|---|---|---|---|
| $49 / мес | маржа 85% | маржа 49% | убыток −53% |
| $99 / мес | маржа 92% | маржа 75% | маржа 24% |
| $199 / мес | маржа 96% | маржа 87% | маржа 62% |
| $299 / мес | маржа 97% | маржа 92% | маржа 75% |

> Вывод: для Power-юзеров плоская дешёвая подписка убыточна — нужна
> либо более высокая цена, либо лимит проектов в тарифе, либо доплата за overage.

**Оплата за проект:**

| Цена за проект | Себестоимость | Маржа |
|---|---|---|
| $19 | $2.5 | **87%** |
| $39 | $2.5 | **94%** |
| $99 | $2.5 | **97%** |

> Pay-per-project устойчивее: маржа не зависит от интенсивности, нет убыточных юзеров.

### Ориентир окупаемости

При среднем чеке **$99/мес за пользователя** и себестоимости **$25** (активный профиль):

- Валовая прибыль с пользователя: **~$74/мес**
- 50 платящих пользователей → выручка $4 950/мес, валовая прибыль ~$3 700/мес
- VPS+API при таком объёме (≈500 проектов): ~$1 263/мес → покрывается с запасом

## 7. Рычаги снижения себестоимости

| Рычаг | Механика | Эффект на «полный» проект |
|---|---|---|
| 5 → 3 варианта чертежей (+2 по кнопке) | −2 картинки/действие | $2.5 → ~$2.1 (−16%) |
| Качество medium → low для превью | −40–55% за картинку | $2.5 → ~$1.3 (−48%) |
| Рычаг 1 + 2 вместе | — | $2.5 → ~$1.1 (−55%) |
| Квота генераций на пользователя | срезает «тяжёлый» хвост | потолок «тяжёлого» $5.2 → ~$2.5 |
| Кэш по хешу формы (в БД) | повтор параметров = $0 | −10–20% в среднем |

**Пример:** рычаг 1+2 на 200 полных проектов/мес: **$513 → ~$233/мес** (экономия ~$3 360/год).

## 8. Риски

| Риск | Влияние | Меры |
|---|---|---|
| **Нет квот на пользователя** | Спам «Перегенерировать» = неконтролируемый расход; один юзер может сжечь $50–100 за вечер | Внедрить лимит генераций/день на seat — приоритет №1 перед платными клиентами |
| Рост цен OpenAI | Прямо бьёт по переменной части | Кэш, выбор модели/качества, мульти-провайдер на будущее |
| Инфра single-point | SQLite + один VPS, ручной бэкап | Postgres + авто-бэкап + CI/CD перед масштабированием |
| Качество AI-планировки | Картинка ≠ CAD-файл (см. техдолг) | Переход на «структура → рендер» (см. roadmap) |

## 9. Итоговые ориентиры

- **Себестоимость проекта:** $1–5 (типично $1.6–2.5)
- **Реалистичный бюджет** (100–200 полных проектов/мес): **$260–510/мес**, **$3–6K/год**
- **С оптимизацией** (рычаг 1+2): **$130–250/мес**
- **Валовая маржа** при цене $99/мес или $39/проект: **>90%**
- **Главный приоритет перед продажами:** квоты на пользователя (защита от слива бюджета)

> Допущения (себестоимость проекта, проектов на пользователя, цена) легко
> подставляются — структура расчёта не меняется. Цифры обновлять по факту
> из дашборда OpenAI при изменении тарифов или модели.
