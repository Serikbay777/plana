# MVP Scope

## Цель MVP

Доказать один сквозной сценарий для концептуальной проработки типового этажа
многоквартирного жилого дома.

## Основной результат

Сохранённый `LayoutProject`, из которого одинаково строятся:

- план типового этажа;
- базовые метрики;
- предварительные проверки;
- квартирография;
- укрупнённая стоимость;
- DXF, PDF и IFC экспорт.

## Входит в MVP

### Входные данные

- ручные параметры участка и здания;
- DXF-контур участка как вспомогательный вход;
- текстовый brief с последующим подтверждением извлечённых параметров;
- выбор одной поддерживаемой жилой типологии.

### Генерация и редактирование

- 3-5 воспроизводимых вариантов типового этажа;
- сравнение вариантов по площади, квартирографии и ограничениям;
- выбор варианта;
- перемещение и базовое изменение помещений;
- сохранение и повторное открытие текущего состояния;
- история версий на минимальном уровне.

### Аналитика

- общая, жилая и продаваемая площадь;
- квартирография;
- базовый коэффициент эффективности;
- укрупнённая стоимость с явным предупреждением о точности;
- прозрачные статусы проверок: `pass`, `warning`, `fail`, `not_checked`.

### Экспорт

- DXF текущего отредактированного layout;
- PDF-лист концепции;
- IFC концептуального уровня;
- JSON модели проекта для диагностики и интеграций.

### Надёжность

- авторизация без небезопасных значений по умолчанию;
- сохранение проекта;
- CI для frontend и backend;
- Sentry и базовые структурированные логи;
- ограничения на AI-запросы и загрузки файлов.

## Не входит в MVP

- полный ручной CAD-редактор;
- рабочая документация;
- DWG export;
- универсальный импорт любых CAD/BIM-файлов;
- автоматическое нормативное согласование;
- точная смета или тендерная ведомость;
- генерация всех типов зданий;
- фотореалистичная визуализация как основной результат;
- командная работа, сложные роли и биллинг.

## Ограничения честности

UI обязан показывать:

- какие входные данные использованы;
- какие проверки выполнены;
- какие проверки не выполнены;
- уровень точности стоимости;
- уровень детализации экспорта;
- что результат является концептуальным.

Зелёный статус нельзя показывать, если соответствующая проверка не запускалась.

## Критерий готовности MVP

Пилотный пользователь может создать проект, получить варианты, выбрать и
изменить планировку, закрыть приложение, вернуться к проекту и экспортировать
именно сохранённую версию. Архитектор подтверждает, что экспорт пригоден как
основа для дальнейшей концептуальной работы.
