утверждений, 4 опровергнуто). Это **карта источников**, а не сами числа:

## Важные выводы

1. **Один документ покрывает геометрию посадки** (озеленение + плотность/КИТ +
   паркинг) — **СП РК 3.01-101-2013**, приложения А и Д. Это первая цель для
   извлечения числовых норм взамен DRAFT-коэффициентов в `engine/plana_engine/norms.py`.
2. **Главный барьер — платный доступ.** На online.zakon.kz/prg.kz у СП РК / СН РК
   видно только демо (титул + оглавление), сами цифры скрыты. Госакты (Генплан,
   санправила, пожарный техрегламент, градрегламент маслихата) — бесплатны на
   **adilet.zan.kz**. Бесплатные полные копии СП есть на сторонних сайтах
   (ektu.kz, Scribd doc 690727273, cadlancer.com, gostperevod) — легальность не
   гарантирована.
3. **Генплан не содержит геометрии** (КИТ/FAR/% застройки/разрывов/инсоляции) —
   делегирует их в ПДП и правила застройки. Из Генплана берём только
   жилобеспеченность (для расчёта числа жителей).

## Не закрыто (требует прямого чтения полного текста)

- Точные числа из приложений СП РК 3.01-101: озеленение, плотность/КИТ (прил. А),
  паркинг (прил. Д).
- Точная норма инсоляции для широты Астаны (~51° с.ш.) — часто называемая «≥2 ч»
  **не прошла верификацию**, нужно сверить по полному тексту ДСМ-52.
- Значения противопожарных разрывов именно для ЖИЛЫХ зданий (табл. 1 прил. 6
  техрегламента №405 ориентирована частично на промпредприятия).
- **Актуальность градрегламента Астаны:** появилось решение маслихата
  №212/26-VIII от 27.08.2024 — не проверено, заместило ли оно №312/39-VI (2018)
  для 2025–2026.
